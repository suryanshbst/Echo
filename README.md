## ✦ What is Echo?

**Echo** is a minimal, real-time chat application built for private, temporary conversations.

- Create a room with one click
- Share the code — anyone with the code joins
- No accounts, no passwords, no persistent history
- Room vanishes when the last person leaves

&gt; *"Where conversations resonate — then fade away."*

## ✦ Tech Stack

| Layer | Technology |
|-------|------------|
| **Frontend** | React 19 + TypeScript + Vite |
| **Styling** | Inline styles (dark aesthetic) |
| **Backend** | Node.js + Express + WebSocket (`ws`) |
| **Deployment** | Render (backend) + Vercel (frontend) |

---

## ✦ Features

- ⚡ **Real-time messaging** via WebSocket
- 🔒 **Private rooms** — 6-character unique codes
- 👤 **User presence** — live online count
- 🌙 **Dark aesthetic** — minimal, noise-textured UI
- 🗑️ **Auto-cleanup** — rooms expire when empty
- 📱 **Responsive** — works on desktop & mobile
